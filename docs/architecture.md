## 🔄 Сигналы и слоты (Qt)

```
ControlPanel
    │
    ├─→ load_image_clicked ──→ MainWindow.load_image()
    ├─→ start_processing_clicked ──→ MainWindow.start_processing()
    └─→ save_result_clicked ──→ MainWindow.save_result()

ProcessingWorker
    │
    ├─→ progress ──→ StatsPanel.log()
    ├─→ zone_processed ──→ MainWindow.on_zone_processed()
    ├─→ finished ──→ MainWindow.on_processing_finished()
    └─→ error ──→ MainWindow.on_processing_error()
```

## 🎯 Разделение ответственности

| Слой | Ответственность |
|------|----------------|
| **UI** | Отображение, взаимодействие с пользователем |
| **Workers** | Многопоточная обработка, не блокирует UI |
| **Core** | Бизнес-логика обработки изображений |
| **Models** | Нейросетевые модели |
| **Config** | Настройки и константы |
| **Utils** | Вспомогательные функции |

## 🔌 Точки расширения

1. **Новые виджеты** → `ui/widgets/`
2. **Новая обработка** → `core/`
3. **Новые модели** → `models/`
4. **Новые воркеры** → `workers/`
5. **Темы** → `ui/styles/`
