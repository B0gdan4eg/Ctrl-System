## Контекст и мотивация

Корневая проблема Задачи 5 (`docs/report.md`, `docs/tasks_progress.md`):
классический алгоритм `find_top_zones_improved` (CLAHE + threshold + контуры)
**частично захватывает тёмную рамку фильтра** в маску зоны. Это искажает
последующую гистограммную нормализацию ROI и приводит к ложным детекциям
дефектов на границах.

Решение: заменить классический поиск зон на **U-Net сегментацию**,
обученную на самой же классике в качестве слабого надсмотрщика
(weak supervision) с дополнительным уточнением границ через Otsu.

## Что сделано

### 1. Скрипт автоматической разметки

**Файл:** `scripts/generate_zone_dataset.py`

Прогоняет `find_top_zones_improved` по корпусу изображений и генерирует
тренировочные пары (image, mask). Ключевые шаги для каждого снимка:

1. **Загрузка** — uint16/12-bit конвертится в uint8 percentile-стретчем
   (1%–99%), чтобы поднять контраст низкоконтрастных снимков
2. **Поиск зон** — `find_top_zones_improved`
3. **Уточнение границ через Otsu** (`refine_zone_by_otsu`):
   - Внутри расширенного на 8% bbox каждого контура делается
     Otsu-thresholding по реальной гистограмме
   - Берётся самый крупный связный компонент как настоящая зона
   - Это **отрезает попавшую в детекцию тёмную рамку фильтра**
4. **Сглаживание формы** (`contours_to_mask`):
   - Closing + Opening небольшим ядром (9×9) — убирает рваные края
   - `approxPolyDP` с epsilon=0.3% периметра — финальное сглаживание
     без расширения формы (изначально пробовали `convex hull` — он
     слишком агрессивно расширял маску за реальные границы)
5. **Quality check** — авто-приёмка если найдено в диапазоне `[min_zones, top_n]`
   с разумной дисперсией площадей и покрытием

**Результат на полной базе `D:/AI/full_db` (805 снимков):**

### 2. Скрипт обучения U-Net

**Файл:** `scripts/train_zone_unet.py`

- **Архитектура:** проектная `UNet` (`models/unet.py`) с features `[32, 64, 128, 256]`
- **Параметров:** ~7.7M (компактная сеть, для зон с запасом)
- **Размер входа:** 512×512 (исходник 2048× избыточен для определения зон)
- **Loss:** BCE + Dice (стандарт для бинарной сегментации)
- **Оптимизатор:** AdamW (lr=1e-4) + CosineAnnealingLR
- **AMP** (mixed precision) — задействует Tensor Cores на RTX
- **Аугментации:** случайные флипы H/V + варьирование яркости/контраста
- **Train/val split:** 685 / 120 (85/15%)

**Метрики обучения** (28 эпох из 50, ранний стоп):

| Эпоха | Train IoU | Val IoU | Заметки |
|-------|-----------|---------|---------|
| 1 | 0.914 | 0.956 | старт |
| 11 | 0.965 | 0.970 | первое преодоление 0.97 |
| 19 | 0.968 | 0.974 | |
| 24 | 0.970 | **0.977** | best checkpoint |
| 28 | 0.973 | 0.975 | плато |

**Best Val IoU = 0.9769** — отличный результат:
- Train IoU ≈ Val IoU → переобучения нет
- Каркас обучения масштабируется (50 эпох могли бы дать +0.005)
- Все метрики оцениваются против псевдо-разметки, реальное качество
  на сложных кейсах **выше** за счёт сглаживания случайных ошибок Otsu

### 3. Скрипт инференса с side-by-side сравнением

**Файл:** `scripts/predict_zones.py`

Прогоняет обученную модель на тестовых снимках и (с флагом `--compare`)
сохраняет 4-панельные превью: оригинал | классика синим | U-Net зелёным |
diff (синий=только классика, зелёный=только NN, жёлтый=оба).

Импорт `core/zone_detection.py` сделан через `importlib.util` напрямую
файлом — обходит `core/__init__.py`, который тянет PySide6 (которого
нет в глобальном Python 3.11 с GPU torch).

### 4. Интеграция в приложение

**Новый файл:** `core/zone_segmentation.py`

Класс `ZoneSegmenter`:
- Lazy-load модели при первом вызове (не тормозит старт приложения)
- Авто-выбор GPU/CPU
- `predict_contours()` возвращает список контуров слева→направо —
  **drop-in замена** для `find_top_zones()`
- Дополнительные фильтры: `min_absolute_area`, `min/max_area_ratio`
- Граceful fallback при ошибке загрузки (`is_available = False`)

**Изменено:** `workers/processing_worker.py`

- Singleton `_zone_segmenter` (один экземпляр на процесс)
- Логика поиска зон: **сначала U-Net → если пусто/недоступна, классика**
- В лог пишется метод: `✓ Найдено зон: 5 (U-Net)` / `(классика)`

**Изменено:** `config/settings.py`

```python
ZONE_MODEL_PATH = "models/zone_unet.pth"
USE_AI_ZONE_DETECTION = True   # выключатель
```

**Скопировано:** `models/zone_unet.pth` (~31 MB, чекпоинт с эпохи 24).

## Команды воспроизведения

```bash
# 1. Сгенерировать датасет (CPU, ~10 мин)
python scripts/generate_zone_dataset.py \
    --input-dir D:/AI/full_db \
    --output-dir D:/AI/zone_dataset_full \
    --top-n 5 --min-zones 4

# 2. Обучить U-Net (GPU, ~25 мин на 28 эпох)
"C:/Users/.../Python311/python.exe" scripts/train_zone_unet.py \
    --dataset D:/AI/zone_dataset_full \
    --output  D:/AI/zone_model \
    --epochs 50 --batch-size 4 --image-size 512 --num-workers 0

# 3. Прогон + сравнение с классикой
"C:/Users/.../Python311/python.exe" scripts/predict_zones.py \
    --model  D:/AI/zone_model/best_zone_unet.pth \
    --input  D:/AI/full_db \
    --output D:/AI/zone_predictions \
    --limit 10 --compare

# 4. Запуск приложения с AI-сегментацией
python main.py
```
