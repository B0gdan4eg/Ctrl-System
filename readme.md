# Система детекции дефектов

Полнофункциональное приложение для автоматической детекции дефектов на изображениях с использованием глубокого обучения (U-Net).

## 📁 Структура проекта

```
defect_detection/
├── main.py                          # Точка входа
├── requirements.txt                 # Зависимости
├── config/
│   └── settings.py                  # Настройки приложения
├── models/
│   ├── __init__.py
│   └── unet.py                      # U-Net архитектура
├── core/
│   ├── __init__.py
│   ├── image_processing.py          # Обработка изображений
│   ├── zone_detection.py            # Детекция зон
│   └── defect_detection.py          # Детекция дефектов
├── workers/
│   ├── __init__.py
│   └── processing_worker.py         # Многопоточная обработка
├── ui/
│   ├── __init__.py
│   ├── main_window.py               # Главное окно
│   ├── widgets/
│   │   ├── __init__.py
│   │   ├── image_viewer.py          # Виджет просмотра
│   │   ├── control_panel.py         # Панель управления
│   │   └── stats_panel.py           # Панель статистики
│   └── styles/
│       └── dark_theme.py            # Темная тема
└── utils/
    ├── __init__.py
    └── logger.py                    # Логирование
```

## 📦 Модули

### 1. **config/** - Конфигурация
- `settings.py` - Все настройки приложения в одном месте

### 2. **models/** - Модели нейронных сетей
- `unet.py` - Архитектура U-Net для сегментации дефектов

### 3. **core/** - Основная логика обработки
- `image_processing.py` - Предобработка изображений (нормализация, фильтрация)
- `zone_detection.py` - Поиск и выделение зон на изображении
- `defect_detection.py` - Детекция дефектов с использованием нейросети

### 4. **workers/** - Многопоточность
- `processing_worker.py` - Воркер для обработки в фоновом потоке

### 5. **ui/** - Пользовательский интерфейс
- `main_window.py` - Главное окно приложения
- `widgets/` - Переиспользуемые UI компоненты
  - `image_viewer.py` - Виджет для отображения изображений
  - `control_panel.py` - Панель управления параметрами
  - `stats_panel.py` - Панель статистики и логов
- `styles/` - Стили оформления
  - `dark_theme.py` - Темная тема

### 6. **utils/** - Утилиты
- `logger.py` - Система логирования

## 🔧 Конвейер обработки

1. **Загрузка изображения** (`image_processing.py`)
   - Чтение файла
   - Конвертация в grayscale

2. **Поиск зон** (`zone_detection.py`)
   - CLAHE enhancement
   - Поиск контуров
   - Фильтрация по размеру

3. **Нормализация** (`image_processing.py`)
   - Mean ± Std Dev нормализация
   - Применяется к каждой зоне

4. **Предобработка** (`image_processing.py`)
   - Bilateral фильтр (шумоподавление)
   - Resize до размера модели

5. **Детекция дефектов** (`defect_detection.py`)
   - U-Net предсказание
   - Бинаризация маски

6. **Визуализация** (`defect_detection.py`)
   - Наложение масок дефектов
   - Рисование контуров зон

## 🎨 UI Компоненты

### ImageViewer
Виджет для отображения изображений с автомасштабированием.

### ControlPanel
Панель управления с параметрами:
- Количество зон для поиска
- Std Range для нормализации
- Порог детекции
- Размер для модели
- Включение/выключение нормализации

### StatsPanel
Панель статистики:
- Лог обработки в реальном времени
- Статистика по зонам
- Информация о дефектах

## 📝 Параметры обработки

Все параметры настраиваются в `config/settings.py`:

```python
DEFAULT_NUM_ZONES = 5              # Количество зон
DEFAULT_MIN_AREA_RATIO = 0.3       # Мин. размер зоны
DEFAULT_MAX_AREA_RATIO = 0.95      # Макс. размер зоны
DEFAULT_STD_RANGE = 2.5            # Диапазон для нормализации
DEFAULT_DETECTION_THRESHOLD = 0.5  # Порог детекции
DEFAULT_MODEL_SIZE = 512           # Размер входа модели
```

## 🔍 Использование

1. Запустите приложение: `python main.py`
2. Нажмите "Загрузить изображение" и выберите файл
3. Настройте параметры обработки (опционально)
4. Нажмите "ЗАПУСТИТЬ ОБРАБОТКУ"
5. Просмотрите результаты во вкладках
6. Сохраните результат при необходимости

## 🛠️ Расширение функциональности

### Добавление нового виджета

1. Создайте файл в `ui/widgets/new_widget.py`
2. Наследуйтесь от QWidget
3. Добавьте в `ui/widgets/__init__.py`
4. Используйте в `main_window.py`

### Добавление новой обработки

1. Создайте функцию в `core/image_processing.py`
2. Добавьте в `core/__init__.py`
3. Используйте в `processing_worker.py`

### Изменение модели

1. Отредактируйте `models/unet.py`
2. Обновите параметры в `config/settings.py`

## 📊 Логирование

Все действия логируются:
- В UI (панель логов)
- В файлы `logs/defect_detection_YYYYMMDD.log`

## ⚙️ Многопоточность

Обработка выполняется в отдельном потоке (`ProcessingWorker`):
- Не блокирует UI
- Отправляет сигналы о прогрессе
- Обрабатывает ошибки
